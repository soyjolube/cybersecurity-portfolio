Linux Commands

This document contains the Linux commands I have learned and practiced during my cybersecurity training.

---

Navigation

"pwd"

Purpose: Shows the current working directory.

Example: "pwd"

---

"ls"

Purpose: Lists files and directories in the current location.

Example: "ls"

---

"cd"

Purpose: Changes the current working directory.

Example: "cd Documents"

Go back to the previous directory: "cd .."

---

Directories

"mkdir"

Purpose: Creates a new directory.

Example: "mkdir projects"

---

"rmdir"

Purpose: Removes an empty directory.

Example: "rmdir projects"

Important: "rmdir" only removes empty directories.

---

Files

"touch"

Purpose: Creates a new empty file.

Example: "touch notes.txt"

---

"cat"

Purpose: Displays the contents of a file in the terminal.

Example: "cat notes.txt"

---

"cp"

Purpose: Copies files or directories.

Example: "cp notes.txt backup.txt"

---

"mv"

Purpose: Moves or renames files and directories.

Example — rename a file: "mv notes.txt notes-old.txt"

Example — move a file: "mv notes.txt Documents/"

---

"rm"

Purpose: Removes files or directories.

Example: "rm notes.txt"

Important: "rm" can permanently delete files. Use it carefully.

---

Learning Notes

"rmdir" vs "rm"

"rmdir" is specifically used to remove empty directories.

"rm" is primarily used to remove files and can also remove directories when used with additional options.

"cat" vs "touch"

"touch" can create an empty file.

"cat" can display the contents of an existing file.
